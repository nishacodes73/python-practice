Student Marks and Grade Checker

Project Description

A beginner-friendly Python program that accepts a student’s name and marks, validates the marks, and displays the result based on the marks obtained.

Concepts Learned

* User input using input()
* Type conversion using int()
* String method: upper()
* Conditional statements: if, elif, and else
* Logical operators: or
* Input validation

What This Project Demonstrates

* Accepting and processing user input
* Checking valid marks between 0 and 100
* Assigning grades based on marks
* Using conditional logic to make decisions
